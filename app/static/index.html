Get started

Upload an original recording, let the audio highlight detector suggest exciting sections, review each candidate, then approve it to create a vertical MP4.

Build 1 uses audio activity to generate candidates. AI speech analysis, automated captions, chat-spike detection and platform OAuth are future integrations, not simulated here.

Upload a recording

MP4, MOV, MKV, WEBM, TS, M4V. Large files depend on your server and storage limits.

Supported video sources

YouTube recordings: upload a file you own or have permission to use. Twitch VODs: upload an authorized recording. A video URL alone does not grant permission to download the footage.

For live inputs, switch to Live Monitor.

Monitor an authorized HLS livestream

Provide a direct HTTPS .m3u8 feed that you control or have been authorized to capture. This is not a Twitch/YouTube URL importer or OAuth connection.

Each completed approximately two-minute segment produces new review candidates while the feed is live. Recording starts only when you click Start. Stream connections stop on server restart; this initial build does not auto-resume.
